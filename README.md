# Night Coffee Digital Showcase

Создай современный персональный сайт-портфолио начинающего Vibe Coder.

Название: My Developer Portfolio.

Язык сайта: русский.

Цель: демонстрировать мои проекты и предлагать услуги по созданию сайтов, цифровых меню и простых Telegram-ботов.

Структура:

Главный экран с заголовком «Создаю сайты и цифровые решения с помощью AI».

Раздел «Мои услуги» с тремя карточками: сайты, цифровые меню, Telegram-боты.

Раздел «Мои проекты» с карточкой Night Coffee Demo и ссылкой https://night-coffee-demo.lovable.app.

Раздел «Обо мне» — начинающий разработчик, изучаю Vibe Coding и создаю практические проекты.

Раздел контактов с кнопкой для связи.

Дизайн: современный, минималистичный, профессиональный. Хорошая адаптация под смартфоны и компьютеры.

Не добавляй вымышленные отзывы, клиентов, достижения или опыт работы. Не придумывай контактные данные. Если контакт для связи неизвестен, оставь место для его добавления.
